IV. ⚠️ CÁC LỖI VI PHẠM NGUYÊN TẮC OOP, SOLID & QUY CHUẨN GEMINI.md CẦN SỬA

1. Lỗi 1: Trả trực tiếp Entity ra ngoài Controller (Vi phạm Điều 2 & Điều 5 GEMINI.md):
   - Trong CourseService, LessonService, SubjectiveService: Các hàm GetAllCourse(), GetCourseByID(), GetLessonsBySubjectId() đều đang trả thẳng Entity của Database (Course, Lesson, Subject).
   - Hậu quả: Khi Controller chuyển sang JSON sẽ bị văng lỗi JSON Cycle (vòng lặp vô tận) do quan hệ Course -> Subjects -> Course. Đồng thời làm lộ cấu trúc bảng SQL.
   - Khắc phục: Bắt buộc ánh xạ (map) sang CourseResponseDTO, LessonResponseDTO.

2. Lỗi 2: Dùng throw new Exception và try-catch thủ công ở Controller (Vi phạm Điều 2 & 5 GEMINI.md):
   - Thắng đang dùng: throw new Exception("Course not found") chung chung.
   - Trong Controller lại bọc try { ... } catch (Exception ex) { return NotFound(...); } ở từng hàm, làm Controller bị dày code (Fat Controller).
   - Khắc phục: Dùng throw new BusinessException("Khóa học không tồn tại"). Controller chỉ cần gọi service và trả về Ok(result), để ExceptionHandlingMiddleware tự động bắt lỗi và trả về HTTP 400 JSON thống nhất.

3. Lỗi 3: Xóa cứng (Hard Delete) thay vì Soft-delete / Tombstone:
   - Trong DeleteCourse, DeleteSubject, DeleteLesson: Đang dùng dbContext.Remove(...) xóa vĩnh viễn khỏi Database.
   - Hậu quả: Làm gãy tính năng Đồng bộ Offline (Client offline sẽ không bao giờ biết bài học đó đã bị xóa trên server để xóa file trong máy). Nên chuyển sang đổi cờ IsPublished = false hoặc ghi log xóa vào ContentChanges.

4. Lỗi 4: Trùng lặp tính năng giữa Tân và Thắng (Feature Overlap):
   - Cả Tân (trên Offline-Frist) và Thắng (trên ThangBranch) đều viết DeviceService và DevicesController.
   - Khi merge 2 nhánh, team NÊN ƯU TIÊN GIỮ BẢN DEVICE CỦA TÂN vì bản của Tân được đặt trong Areas/Device/ và có tích hợp đầy đủ Validation Factory trong thư mục Infrastructure/Validation/Device/.

5. Lỗi 5: Gom toàn bộ DTO vào 1 file duy nhất DTOs/dto.cs:
   - File dto.cs chứa hơn 15 record DTO các loại và có một class rỗng "public class dto {}". Cần tách ra các file riêng: CourseDTOs.cs, LessonDTOs.cs, QuizDTOs.cs, ProgressDTOs.cs.
