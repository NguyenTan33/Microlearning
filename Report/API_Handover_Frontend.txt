--------------------------------------------------------------------------------
[API 1] DANG KY THIET BI HOC VIEN (DEVICE REGISTRATION)
--------------------------------------------------------------------------------
* Mo ta: Goi ngay khi nguoi dung dang nhap thanh cong hoac vua mo App Mobile.
  Backend se tu dong boc AccountId tu JWT de lien ket voi thiet bi theo co che
  Idempotent Upsert (neu da co thi cap nhat thong tin os/model, khong crash).
* Method: POST
* URL: /api/devices/register
* Headers: Authorization: Bearer <token>
* Body JSON:
{
  "deviceId": "samsung_s23_uuid_123456",
  "platform": 1,
  "deviceModel": "Samsung Galaxy S23 Ultra",
  "osVersion": "Android 14"
}
(Ghi chu Platform: 1 = Android, 2 = iOS)

* Response (HTTP 200 OK):
{
  "id": 1,
  "deviceId": "samsung_s23_uuid_123456",
  "platform": "Android",
  "deviceModel": "Samsung Galaxy S23 Ultra",
  "osVersion": "Android 14",
  "lastSyncAt": null,
  "createdAt": "2026-10-04T10:00:00Z"
}


--------------------------------------------------------------------------------
[API 2] PHAT VA TUA VIDEO TRUC TUYEN (HTTP 206 RANGE STREAMING)
--------------------------------------------------------------------------------
* Mo ta: Trinh phat video (React Native Video / Flutter Video Player / HTML5 Video)
  truyen truc tiep URL nay vao. Backend ho tro chuan Byte-Range (HTTP 206), cho phep
  tua video toi/lui ngay lap tuc ma khong can cho tai het toan bo tep.
* Method: GET
* URL: /api/media/{id}/stream
* Vi du goi thuc te: https://localhost:7184/api/media/1/stream
* Headers: Trinh duyet/Player tu gui kem header:
  Range: bytes=0-1048576
* Response: HTTP 206 Partial Content (Luong du lieu video dang binary stream).

[API 5] KEO BIEN DONG VI SAI (DELTA SYNC PULL)
--------------------------------------------------------------------------------
* Mo ta: Mobile dinh ky (hoac khi co mang lai) goi API nay de keo toan bo noi dung
  thay doi moi nhat ve may. Chi keo nhung thay doi co Sequence lon hon moc
  `afterSequence` ma dien thoai dang luu o local.
* Method: GET
* URL: /api/sync/pull?afterSequence={seq}&limit={limit}
* Vi du: /api/sync/pull?afterSequence=0&limit=50
* Headers: Authorization: Bearer <token>
* Response (HTTP 200 OK):
{
  "changes": [
    {
      "sequence": 1,
      "entityType": "Lesson",
      "entityId": 10,
      "changeType": "Created",
      "version": 1,
      "changedAt": "2026-10-04T12:00:00Z"
    },
    {
      "sequence": 2,
      "entityType": "Lesson",
      "entityId": 5,
      "changeType": "Deleted",
      "version": 2,
      "changedAt": "2026-10-04T12:30:00Z"
    }
  ],
  "lastSequence": 2,
  "hasMoreChanges": false
}

* QUY TAC XU LY PHIA MOBILE:
  1. Luu `lastSequence` nhan duoc vao local storage (vi du Preferences / SQLite).
  2. Lan goi ke tiep truyen `afterSequence = 2`.
  3. Neu `changeType == "Deleted"`: Day la co che TOMBSTONE. Mobile phai lap tuc
     xoa file video cache cua bai hoc do va xoa khoi DB offline de giai phong dung luong!

[API 6] DAY HANG DOI THAO TAC OFFLINE LEN SERVER (OUTBOX BATCH SYNC PUSH)
--------------------------------------------------------------------------------
* Mo ta: Khi dien thoai hoc offline (xem video, lam quiz), Mobile ghi vao bang
  Outbox o SQLite. Khi co mang tro lai, Mobile gom toan bo thanh 1 mang batch va
  gui len endpoint nay. Server xu ly trong 1 Transaction ACID duy nhat.
* Method: POST
* URL: /api/sync/push
* Headers: Authorization: Bearer <token>
* Body JSON:
{
  "operations": [
    {
      "clientOperationId": "c3a9f0e1-7b2a-4a1d-8e4f-5c2d1b0a9e8f",
      "operationType": "LESSON_PROGRESS",
      "deviceTimestamp": "2026-10-04T14:00:00Z",
      "payload": "{\"lessonId\": 1, \"progressPercent\": 85, \"isCompleted\": true}"
    },
    {
      "clientOperationId": "d4b1a2e3-8c3b-5b2e-9f5a-6d3e2c1b0f9a",
      "operationType": "QUIZ_ATTEMPT",
      "deviceTimestamp": "2026-10-04T14:15:00Z",
      "payload": "{\"quizId\": 1, \"clientAttemptId\": \"f5c2b3d4-9d4c-6c3f-0a6b-7e4f3d2c1a0b\", \"answers\": [{\"questionId\": 1, \"selectedOptionId\": 2}]}"
    }
  ]
}

* Response (HTTP 200 OK):
{
  "syncedCount": 2,
  "serverTimestamp": "2026-10-04T14:20:00Z",
  "results": [
    {
      "clientOperationId": "c3a9f0e1-7b2a-4a1d-8e4f-5c2d1b0a9e8f",
      "success": true,
      "message": "Dong bo tien do bai hoc thanh cong."
    },
    {
      "clientOperationId": "d4b1a2e3-8c3b-5b2e-9f5a-6d3e2c1b0f9a",
      "success": true,
      "message": "Cham diem va ghi nhan ket qua quiz thanh cong."
    }
  ]
}

* DAC DIEM QUAN TRONG CHO MOBILE:
  - Thuat toan Monotonic Merge: Backend tu dong ap dung Math.Max(). Neu hoc vien
    da dat 90% tren may tinh, roi sang dien thoai offline gui 50% len, Backend van
    giu nguyen 90% de tien do khong bao gio bi thut lui!
  - Co che Chuyen sau Idempotency: Neu Mobile bi chap chon mang gui lai dung mang
    tren, Backend se tu dong bo qua ma khong gay loi va khong nhan doi diem so!

3. HUONG DAN TICH HOP CHO DOI FRONTEND & MOBILE DEV
================================================================================

1. KHOI TAO PHIA MOBILE:
   - Moi thiet bi khi cai app phai sinh 1 `deviceId` duy nhat (UUID).
   - Luu bien `last_pulled_sequence` (khoi tao = 0) trong SQLite / SharedPreferences.

2. KICH BAN KEO DU LIEU (PULL):
   - Khi mo app hoac co mang: Goi `GET /api/sync/pull?afterSequence={last_pulled_sequence}`.
   - Luu tat ca ban ghi nhan duoc vao local DB.
   - Neu ban ghi co `changeType == "Deleted"`: Xoa bai hoc va xoa file video tuong ung
     trong bo nho may dien thoai.
   - Cap nhat `last_pulled_sequence = response.lastSequence`.

3. KICH BAN DAY DU LIEU (PUSH):
   - Khi hoc vien xem video hoac lam bai: Luon luu thao tac vao bang SQLite `Outbox`
     kem 1 ma UUID `clientOperationId` sinh ngau nhien cho moi thao tac.
   - Khi co mang: Lay toi da 50 thao tac tu Outbox -> Goi `POST /api/sync/push`.
   - Neu nhan ve HTTP 200 OK: Xoa cac ban ghi tuong ung khoi bang `Outbox` o dien thoai.
   - Neu that bai (khong co mang): Giu nguyen trong Outbox de gui lai lan sau.

4. AN TOAN DU LIEU:
   - Backend da hoan tat 100% logic Monotonic Merge, Deduplication, Server-side Quiz
     Grading, Rate Limiting va HTTP 206 Streaming. Doi FE co the tich hop ngay lap tuc!
